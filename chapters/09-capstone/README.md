## The part's single idea

The curriculum's parts each owned a stage; the capstone owns the **integration claim**: that a governed corpus, an access-filtered pipeline, a labeled assembly, an honest refusal, and an evaluation harness compose into a system you can *defend from artifacts* — traces, golden cases, ablations, security tests. The capstone defense is the graduation exam: any behavior, any question, answered in seconds from evidence.

## Completion criteria

- [ ] You have extended the assistant (or built its analog) with corpus content and golden cases of your own.
- [ ] You have run one honest ablation and can state its limitation paragraph.
- [ ] You can do the 30-minute defense and every question resolves to an artifact.
